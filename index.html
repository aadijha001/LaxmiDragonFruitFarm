Local Server Required

Because this app loads its data dynamically from data.json, modern web browsers block this request when opening the file directly (via file://).

To view the website, please run a local web server:

  • Open your terminal in this project folder and run:
    • npx serve
  • Or using Python:
    • python3 -m http.server 8000
  • Then open the link shown in your terminal (usually http://localhost:3000 or http://localhost:8000).
